INTERACTIVE CPU SIMULATOR
Computer Organization and Architecture (COA) Mini Project

HOW TO RUN
1. Extract the project folder.
2. Open index.html in Google Chrome, Microsoft Edge, or another modern browser.
3. Enter instructions or use the default example.
4. Click STEP to observe each stage of the instruction cycle.
5. Click RUN ALL to execute the complete program automatically.

PROJECT COMPONENTS
- Registers: R1, R2, R3, R4, Program Counter (PC), Instruction Register (IR)
- Memory simulation
- Arithmetic Logic Unit operations
- Control Unit simulation
- Fetch, Decode, Execute, Memory Access and Write Back stages

SUPPORTED INSTRUCTIONS
LOAD R1, 10
STORE R1, 20
ADD R1, R2
SUB R1, 2
AND R1, R2
OR R1, R2
XOR R1, R2

NOTE
This is an educational simulation. It demonstrates fundamental CPU concepts and is not intended to emulate a real processor instruction set.
